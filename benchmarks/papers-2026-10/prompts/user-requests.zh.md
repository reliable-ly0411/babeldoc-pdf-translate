# 测试例参考请求

这些是便于复现的用户层请求。真实作业中注入模型的是 [technical.txt](technical.txt)、BabelDOC 构建的页面片段/保护标记协议，以及适用的术语 CSV；这里不伪称已经逐字回放了桌面 GUI 对话。

- **全文英译中**：将对应论文从英语完整翻译为简体中文，保留图片、数学式、单位、数字、代码、引用和版式；同时生成中文单语和原文在左的双语 PDF。按术语表保持控制、航空和强化学习术语一致，分块最多 5 页。先运行对应代表页检查。
- **Stein 代表页**：先翻译原文物理第 3、7 页，输出单语/双语及有水印/无水印两种变体，检查积分、根号、首字下沉和行内公式。
- **Swift 代表页**：选第 2、7、14 页，启用术语候选提取及保存，使用 sans-serif；分别检查照片、矩阵和表格。明确像素表格是否仍是英文。
- **Dueling 代表页**：选第 4、8 页，以译文在前的交替双语输出，检查公式占位符、双栏及密集比较图。保护标记不能保留时报告失败。
- **中文译英文**：对固定中文控制件以及显式准备的 Swift/R1 回译输入执行中文到英文；Swift 采用译文在前的交替双语。覆盖、公式和标点需重新检查，不能用“能回译”证明初译正确。
- **其他语言**：只把单页英文控制件译为法语、单页中文控制件译为日语，再分别回译英文/中文；保留 CTRL-2026-A、负号、100 Hz、0.02 s 和公式，检查首尾字符和标点。
- **扫描负例**：对固定栅格化控制件分别运行 off/auto/force；没有完整 PDF 或没有译文时必须报告失败，不得用复制图片当作完成翻译。

控制件的英文与中文源码互为参考，见 [fragment-en.txt](fragment-en.txt)、[fragment-zh.txt](fragment-zh.txt)。判断重在否定词（不能保证所有扰动下安全）、参考轨迹、数值与单位不变、标识符连字符不变；允许自然语言措辞变化及法语小数本地化，但不允许公式/代码的符号变化或残缺字符。归档 PDF 是实际机器结果；缺陷状态见各参考目录与报告，没有把机器输出自动当作 gold 标准。
